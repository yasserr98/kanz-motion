# House: current shorts scene example

Copy this scene for shorts following [the shorts route](../../docs/routes/shorts.md). It demonstrates PACE-1/5 and
SHORT-3/4/6/7/8: current defaults, a registry title, voice-derived duration and clean cuts without face jump zooms.
The delivered Reel used an older look; this teaching copy is not its archival scene.

The complete example cannot render in a fresh clone: face frames and voice audio stay local. The tracked timings
also predate the title registry. Copy the template into a local project, extract its footage, write corrected captions,
add that project's slug and three title options to local `shorts/_titles.json`, then rebuild captions as the route
describes. `K.title()` reads the selected title from that generated timing data.
