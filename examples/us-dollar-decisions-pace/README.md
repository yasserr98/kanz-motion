# Dollar: current scene example

Copy this scene for script and voice-note Reels. It demonstrates PACE-1..6 and EXPL-1 with the
2026-10-18 defaults. The delivered Reel used an older look; this teaching copy is not its archival scene.

Its opening (section 1) still uses a static hero icon, which new Reels no longer do: open on a drawn scene in the
Live C v10 style that moves with the opening words (HOOK-1..4). `projects/_template/scene.js` shows that opening;
copy the rest of this scene as before.

Stills can render from the tracked timings and assets without local voice media. A full MP4 needs the private voice
audio. The setup smoke command is `python engine/make.py review us-dollar-decisions-pace 3,20,45`.
